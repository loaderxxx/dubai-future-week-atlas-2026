# Dubai Future Week 2026 · Public Atlas

Независимый рабочий атлас публичной программы **18–21 ноября 2026**, Emirates Towers и Museum of the Future, Dubai. Не официальный продукт организатора. Проверено 18 ноября 2026. Всё время — Dubai (UTC+4).

## Что собрано

- [265 записей спикеров](data/speakers.csv): полный ответ официального публичного каталога на дату проверки, не список всех посетителей.
- [263 записи программы](data/sessions.csv): 279 записей API минус 16 помеченных `web_programme` hidden. 196 public и 67 invite_only; публичное описание закрытой сессии не даёт права входа.
- [100 проектов Prototypes for Humanity 2026](data/prototypes.csv): каталог проектов, не 100 зарегистрированных компаний.
- [Организации и партнёры](data/organizations.csv): роли и ссылки; каталог не означает наличие стенда или представителя в конкретный час.
- [Приоритеты людей](docs/people-priorities.md), [организаций](docs/organizations-priorities.md), [маршрут и доступ](docs/visit-plan-ru.md).
- [Методология и ограничения](docs/methodology.md).

Открыть `docs/visit-plan-ru.md`; затем фильтровать CSV по дате, access_level, организации и теме. Поля source/source_url ведут на официальные первоисточники. JSON доступен для последующего интерфейса или графа связей.
