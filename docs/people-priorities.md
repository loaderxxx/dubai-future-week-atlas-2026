## Practical conversation boundaries
- Start by asking about a concrete workflow, accountable owner, current bottleneck, integration and acceptance criteria.
- Offer a short demo or paid pilot only within actual tested capabilities; do not claim autonomous production operation.
- Directory presence does not grant permission to email, scrape personal information or enter invite-only sessions.
- Re-check the official programme/app immediately before attending. Several speaker records represent entire multi-speaker blocks rather than individual talk times.
- Catalog currently has 265 records; other websites showing 226 or five speakers are not exhaustive current catalogs.

## Files
- `speakers.csv`: one row per directory record, role, organization, profile/source URL, website and embedded sessions.
- `speakers.json`: equivalent structured JSON.
- Both exclude full biographies, photographs, personal social handles and country fields. Public professional profile links are kept.
