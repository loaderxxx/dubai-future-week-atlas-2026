# Углублённое исследование: прогресс, не обещание полноты

Дата:18Nov2026. Базовый каталог и углублённые профили — разные уровни работы.

## Очередь

`queue.csv` охватывает265 записей людей,201 точное название организаций из партнёрского каталога и работодателей спикеров,100 проектов. 201 — не число разных юридических лиц: алиасы, подразделения и составные названия ещё требуется нормализовать. Не каждая запись организации является корпорацией.

Статусы:
- `catalogued_not_deeply_researched`: известны имя/роль/источник; глубокий профиль ещё не выполнен.
- `initial_profile`: прочитан исходный материал и явно отмечены пробелы; это не завершённый глубокий аудит.
- `researched_with_gaps`: несколько первичных источников, направления и профессиональные вопросы, границы проверки.

## Порядок партий

1. Публичные сегодняшние встречи: Chamber AI Hub, DFF, Ayman Itani/Think Media Labs, Tom Gruber/Humanistic.AI, Kanwal Aalijah, Khalifa Alqama; проекты Litmus и SystemsML.
2. Остальные сегодняшние AI/technology/governance участники и8 Concept Partners.
3. Все остальные люди и организации: последовательно с проверкой первичных источников, без генерации фиктивной глубины по одному названию.
4. Обновление источников и расписания по мере изменения программы.

## Стандарт профиля

Идентификация → подтверждённая связь с событием → деятельность/продукты/исследования → первичные источники → непроверенное → профессиональные вопросы. Независимая оценка эффективности не подменяется маркетинговым заявлением. Не включаются личные отношения, переписки, финансовые догадки, контакты из приватных аккаунтов, персональные оценки и коммерческие планы конкретного пользователя.

Ни один статус не означает согласие человека на контакт, доступ на закрытую сессию или подтверждённую встречу. Outreach не выполняется.
